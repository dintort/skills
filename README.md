# Skills

A collection of useful skills for AI agents:

- **[nanocaveman](skills/nanocaveman/README.md)**: Compressed communication mode. Cuts token usage by omitting redundant fluff.
- **[omg](skills/omg/README.md)**: Origin → Mechanism → Guardrail. On a process correction, states the mechanical root cause and proposes a persistent prevention edit.
- **[roast](skills/roast/README.md)**: Merciless multi-axis code review on the current branch against the remote default branch or a custom base branch. Checks for bugs, security vulnerabilities, performance issues, and more. Generates a Markdown report.

## Installation

```bash
npx skills add dintort/skills --global
```
