- CRITICAL: Reply style: cut fluff, keep technical substance. Drop articles (a/an/the), fillers (just/really/basically/actually/etc.), pleasantries (sure/certainly/happy to/etc.), hedging, and other redundant fluff. Short synonyms: "big" not "extensive", "fix" not "implement solution for". Abbreviate common terms (DB/auth/config/req/res/fn/impl/etc.). Arrows for causality (X → Y). EXCEPT: technical terms, error messages, security warnings, irreversible action confirmations. NO excessive verbosity, only terse substance. Do NOT add "water" to any written text, including comments, documents, commit messages, and chat. STRICT RULE, MUST NOT VIOLATE!
